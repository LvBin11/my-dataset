# DS-KG-Data-Small：数据结构学科知识抽取数据集（精简版）

本仓库提供《数据结构》学科知识图谱构建任务中使用的**精简版**知识抽取数据集 **DS-KG-Data-Small**，用于实体识别与关系抽取模型的训练与评测。

完整数据集因版权限制暂不公开，本精简版数据集旨在为研究者提供代表性样本，便于方法验证与结果复现。

## 📁 数据集概述

- **来源**：基于《数据结构》学科三元组，通过异构文本模板反向构造   
- **规模**：共 1405 条潜在样本，筛选后抽取 500 条（训练集 350 条，验证集 50 条，测试集 100 条）   
- **覆盖范围**：涵盖 1 类实体（“概念”）、8 类关系，文本内容模拟包含自然语言、数学公式、代码片段等异构特征   
- **生成方法**：采用模板填充方式，根据三元组的头实体、尾实体和关系类型，选择合适的异构文本模板进行生成。此方法旨在为无法获取原始语料库 D 的情况提供替代方案，生成“伪真实”文本。

## 📝 数据格式说明

每条数据为一个 JSON 对象，包含以下字段：

| 字段       | 类型   | 说明                                                         |
|------------|--------|--------------------------------------------------------------|
| `id`       | string | 样本唯一标识符                                               |
| `text`     | string | 原始文本片段                                                 |
| `entities` | list   | 实体列表，每个实体包含 `text`（实体文本）、`start`（起始位置）、`end`（结束位置）、`type`（实体类型） |
| `relations`| list   | 关系列表，每个关系包含 `head`（头实体文本）、`tail`（尾实体文本）、`relation`（关系类型） |

### 示例

```json
{
  "id": "KG_0001",
  "text": "快速排序的平均时间复杂度为O(n log n)，是一种不稳定的排序算法。",
  "entities": [
    {"text": "快速排序", "start": 0, "end": 4, "type": "算法策略"},
    {"text": "O(n log n)", "start": 9, "end": 17, "type": "属性指标"},
    {"text": "不稳定", "start": 21, "end": 24, "type": "属性指标"}
  ],
  "relations": [
    {"head": "快速排序", "tail": "O(n log n)", "relation": "拥有属性"},
    {"head": "快速排序", "tail": "不稳定", "relation": "拥有属性"}
  ]
}
```

🧪 **数据构建说明**

本精简版数据集采用**模板填充**的方式生成。由于原始语料库 D 未能定位，我们根据《数据结构》学科的三元组（头实体、关系、尾实体），通过预定义的异构文本模板反向构造文本。这些模板旨在模拟真实教材中的自然语言描述、数学公式（如 `O(n log n)`）和代码片段（如 `struct Node {{ int data; Node* next; }};`），以体现异构特征。最终，从生成的潜在样本中随机抽取 500 条作为精简版数据集。
